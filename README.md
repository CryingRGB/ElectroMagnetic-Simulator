# Electromagnetic Field Simulator

A real-time 2D electromagnetic field simulator built with Python and Pygame.

The simulator allows users to interact with electromagnetic objects and visualize electric and magnetic fields in real time.

## Features

- Real-time electromagnetic field visualization
- Movable electric charges
- Electrons and positrons
- Magnetic monopoles
- Bar magnets
- Current-carrying wires
- Charge rings
- Current rings
- Uniform magnetic field regions
- Electric field lines
- Magnetic field visualization
- Electric potential visualization
- Interactive objects
- Euler and Boris Integration
- Pause/resume simulation
- 120 FPS target

## Controls

| Key | Action |
|---|---|
| E | Toggle electric field visualization |
| B | Toggle magnetic field visualization |
| O | Toggle probe
| P | Pause/unpause simulation |
| C | Clear playarea
| Shift | Inverse mode |
| Ctrl | Collidable mode |
| Alt | Oscillating mode |



Objects can be interacted with using the mouse.

## Requirements

- Python 3.x
- Pygame
